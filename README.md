📻 Better Car Radio PWA

Full-Stack Media Architecture Demo

Backend & API Architecture

C# .NET Core API: Centralized "Stream Resolver" with self-healing logic.
Server-Side Caching (IMemoryCache): Aggregates metadata from 3rd-party APIs without rate-limiting penalties.

DevOps & Infrastructure

IIS Environment: Hosted on a secured server.
Off-Root Credential Storage: Isolates sensitive data from the webroot.
AppPool Identity Permissions: Granular security settings.
Context-Aware Recursive Proxy: Detects browser bugs and dynamically routes traffic to preserve bandwidth.

Frontend PWA

Vanilla JS (ES6+): Lightweight, high-performance frontend.
Glassmorphism UI: Responsive design with real-time metadata updates.
HLS.js with Native Fallbacks: Robust audio engine for seamless streaming.
